# Global Superstore 2016 Dashboard

This dashboard presents an interactive analysis of the 2016 Global Superstore sales data, including sales, profit, orders, and customer information. The data comes from the 'Orders' sheet of the provided Excel file, covering over 51,000 transactions across multiple regions and product categories.

## Key Findings
- **Total sales** reached $12,649,677 and **total profit** was $1,473,755.
- The **most profitable region** was Western Europe, generating $220,627 in profit.
- **Technology** was the top-selling category with $4,748,657 in sales.
- The **Consumer** segment had the most orders, with 26,519 transactions.
- The average discount given was 14.29%.

## Dashboard Features
- **Bar Chart:** Shows the top 15 products by sales. Use the "Category" dropdown to filter products by category.
- **Pie Chart:** Displays sales distribution by segment. Use the "Region" dropdown to see segment sales for a specific region.
- **KPIs** and **insights** summarize the most important numbers and trends.
- A preview table shows the first 10 orders for quick reference.

The file `analysis.py` contains the full Python script used to generate this dashboard. All files are available in the GitHub folder: `reports/2026-11-14-global_superstore_2016_1_4_1_-7031/`.
